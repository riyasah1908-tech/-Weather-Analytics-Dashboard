# 🌦️ Weather Analytics Dashboard

## 📌 Project Overview

A modern **Weather Analytics Dashboard** designed to display current weather conditions, forecast trends, air quality, and other important environmental metrics in a visually appealing interface.

The dashboard combines a dark theme with vibrant orange accents, interactive-style cards, and charts to make weather information easier to explore.

## ✨ Key Features

- 🌡️ Current temperature and weather conditions
- 📅 Multi-day weather forecast
- 🌅 Sunrise and sunset timings
- 💧 Humidity and precipitation monitoring
- 💨 Wind speed and atmospheric pressure
- 👁️ Visibility and UV index
- 🌫️ Air Quality Index (AQI) and pollutant readings
- 🌧️ Chance of rain visualization
- 📍 Weather information for multiple cities

## 🎯 Project Objective

The goal of this project is to present multiple weather and environmental indicators in one dashboard, making complex information easier to understand at a glance.
